# 🏧 ATM UI System (Unity)

Unity로 제작한 **ATM(입출금) UI 시스템** 프로젝트입니다.  
입금 / 출금 / 잔액 관리 / 오류 팝업 등을 포함한 실제 ATM 동작 흐름을  
UI 중심으로 구현한 예제 프로젝트입니다.

---

## ✨ 주요 기능 (Features)

### 🔹 1. 입금(Deposit)
- 10,000 / 30,000 / 50,000 원 **빠른입력 버튼**
- 직접 금액 입력(InputField)
- 금액 검증 (숫자만 입력 가능)
- 입금 성공 시 사용자 데이터 자동 갱신

### 🔹 2. 출금(Withdraw)
- 동일한 금액 선택 버튼 제공  
- 입력한 금액이 잔액보다 많을 경우 오류 팝업 표시
- 출금 성공 시 잔액 업데이트

### 🔹 3. UserData 저장 구조
- `Name`, `Cash`, `Balance` 값을 가지는 UserData 클래스
- Inspector에서 기본값 설정 가능
- GameManager 통해 싱글톤으로 접근

### 🔹 4. 팝업 및 에러 처리
- 잔액 부족 / 입력 오류 시 팝업 표시
